# Programação para Estatística 

Bem-vindo ao repositório da disciplina de **Programação para Estatística**. Este espaço é dedicado a documentar toda a minha jornada de aprendizado, organizando códigos, listas de exercícios e projetos práticos desenvolvidos durante o curso de Estatística da UFSCar.

O objetivo principal deste repositório é aplicar conceitos teóricos da estatística na prática computacional, construindo uma base sólida para a análise exploratória e ciência de dados.

##  Estrutura do Repositório

* **`/exercicios`**: Resoluções de listas práticas.
* **`/projetos`**: Trabalhos maiores, envolvendo tratamento de dados, simulações estatísticas e visualização.

##  Tecnologias e Ferramentas

* **Linguagens**: Python
* **Ambientes**: Jupyter Notebook
* **Versionamento**: Git e GitHub
